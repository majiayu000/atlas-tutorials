## 如何复跑

从包根目录运行 README 的单元测试和 tests/run_smoke.py。新建一个离线输出目录，不能覆盖真实 run 目录。原 smoke 的全部派生媒体未重复打包；必要输入小样位于 offline-fixtures/，脚本能够重新生成。更新脚本后需重新测试，不能沿用旧报告当作新版本的证据。

包内哈希在最终构建后写入 SHA256SUMS.txt。它验证字节完整性，不是数字签名、供应链认证或内容质量保证。
