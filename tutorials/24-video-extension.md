# 24｜延长已有视频：接缝、动作和声音怎样检查

延长已有视频要检查三件事：模型是否真的使用原视频、接缝是否连续、声音是否衔接。本篇先完成视频延长的能力检查，再把生成片段与已有素材组合；没有该模型能力时提供一个本地剪辑替代，但明确它不等于生成式延长。

## 能力分支

在目录搜索 video extend，读取实际模型说明，确认输入是整段视频、末帧、还是一个已有生成任务引用。普通 image-to-video 从末帧生成后续片段，只能称“末帧续接”，不能冒充原生视频延长。不要创建未经证实的 `atlas extend` 命令。

## 复制给 Agent

> 我要延长这段获授权的视频。先确认 Atlas 当前账号有没有相应模型，核对输入类型、时长上限、声音处理和输出是完整视频还是新增片段。批准后只提交一次。若没有能力，不生成替代任务；给出末帧续接或本地剪辑的区别，让我选择。

## 准备原片

保存原始文件，不在其上覆盖。检查实际帧率、时长、色彩与音轨。最后一秒应有稳定且可延续的动作；快速切镜、黑场、片尾字幕通常不适合直接延长。必要时先剪到一个合理接点，但保留剪切记录。

```bash
python3 scripts/media_audit.py assets/original.mp4 --decode \
  --output tutorial-output/extend/original-audit.json
```

## 参数与提交

支持视频输入的模型，按 schema 使用 `--video` 或对应字段，在 explain 中核对原文件确实进入请求。只接末帧的模型则按教程19执行，并在记录中标注路线。实际时长与分辨率依模型能力选择，不能假定请求5秒就一定精确返回5秒。

收到结果先检查其内容是“原片加新增部分”还是“仅新增部分”。把完整结果再拼到原片后，会重复播放原内容；必须先核对这一点。

## 接缝检查

在接点前后各看一小段，比较主体位置、速度、运动方向、曝光与镜头轨迹。声音另听爆音、突变与重复对白。跨淡化只能遮盖轻微差异，不能修复身份改变或动作逻辑错误。字幕时间轴需要按最终剪辑重新检查。

## 本地替代与恢复

用户接受停格或重复镜头时，可在编辑器里复制片段/保持末帧，并清楚标为剪辑扩展；不能声称模型预测了后续动作。生成超时沿用原 ID；接缝失败只重做新增部分。交付原片、新增片段、最终版与接点审核记录。
