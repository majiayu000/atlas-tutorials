23｜用首尾帧控制镜头，识别模型的能力边界

首尾帧控制的目标是让一个镜头从给定画面开始，在给定画面附近结束。中间运动是否自然仍需要检查。本篇制作一个产品从正面转到轻微侧面的短镜头，不把两个完全不同的物体强行当成连续状态。

先确认存在这项能力

查询当前模型 schema，确认有两个不同的图像输入或其他正式支持的首尾帧机制。CLI 存在 --end-image 这个选项不代表所有模型都接受它。没有对应能力就停在选型，或经用户同意改为两段镜头剪辑；不能把第二张图塞进 prompt 假装执行了控制。

准备两张相容的图

保持产品、光照和画幅一致，末帧只改变合理的角度或位置。先按教程16调整两图尺寸，检查输入图本身有没有标签变化。两张参考相矛盾时，模型可能扭曲中间帧；先修输入比长提示词更可控。

复制给 Agent

使用这两张获批准的图片作为开始与结束状态。先查 Atlas 当前模型是否真的支持首尾帧；支持后展示两个输入字段及费用认知，不上传或生成。批准后提交一次，完整检查起点、终点和中间运动；没有该能力就明确停止，不退化成普通文生视频。

CLI 预览示例

只有当前模型与 CLI 的映射都已确认时才执行：

MODEL='替换为支持首尾帧的真实模型ID'
atlas models get "$MODEL" --json
atlas generate video "$MODEL" \
  -p 'A continuous gentle orbit from the first reference to the final reference. Preserve product geometry and markings.' \
  --image @assets/start.png --end-image @assets/end.png --explain --json

在预览里确认两个文件都映射到实际输入，不要忽略未知字段警告。根据 schema 补时长和画幅，再按教程19的授权、提交、续查流程执行。上传和价格限制与其他参考图任务相同。

验收：不能只看两头

保存实际视频，分别比较首帧、末帧与输入，再慢放中间运动。检查是否出现交叉溶解式变形、物体翻转、文字漂移或突然切换。第一帧压缩/色彩差异不必要求字节完全相同，但内容偏差应有明确容忍标准。

失败与交付

中间动作复杂时先缩小角度、延长允许时长或改变镜头设计，任何新的生成都计入授权。结果只能完成起点却无法符合终点时，报告部分完成，不说“首尾帧锁定成功”。交付参考对照、真实视频、模型与任务记录。
