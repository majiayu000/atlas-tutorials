# 交付检查单

## 文件事实

记录服务端任务 ID、原始结果类型、下载位置、文件大小和 SHA-256。确认不是 HTML 错误页、过期签名链接或仅供预览的缩略图。扩展名必须符合实际文件格式；改名不构成转码。多文件产物逐个登记，不能只保存第一张预览图便声称交付了 3D 模型。

## 技术规格

图片检查像素尺寸、裁切、透明通道、色彩管理和可读性。视频检查显示方向、SAR/DAR、帧率、时长、音频和完整解码。字幕检查起止时间、超界、重叠、文字和显示区域。3D 检查比例、朝向、材质、贴图和目标引擎导入。

## 内容验收

保留项逐条对照原输入，例如产品形状、Logo、价格数字、姓名、讲稿读法、角色衣着。视觉盲评记录原始评分与审稿人，不把生成模型自身的“已完成”当作质量判断。音视频必须在时间维度检查，首帧截图不能证明全片一致。

## 结果表述

把“已完成”“未达标”“未验证”分开。下载失败时给已有任务和真实链接；没有 ID 时保留受理未知。不要用新的生成掩盖原任务故障。示例中的目标阈值只是教学规格，需要按实际渠道和项目修改。

## 机器清单

使用 `scripts/manifest.py --root 交付目录 --output 清单路径` 为交付目录创建文件清单；不要让扫描目录包含凭据和未脱敏回执。验收详情可使用 `examples/config/delivery-review.json`。文件摘要证明字节一致，不证明内容真实性或拥有许可。
