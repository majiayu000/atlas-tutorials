# 33｜把横版视频重构为竖版，保留主体与字幕

把横版视频变成竖版，至少有补边保留、中心裁切和逐镜头重构三种方法。先根据内容选择，而不是把整条视频的两侧统一切掉。代码能保证输出尺寸，主体、屏幕文字和字幕能否留下，需要实际检查。

## 先做镜头清单

观看母版，记录每次切镜与主要主体位置。演示软件界面时，画面两端可能都有必要信息；多人对话时，中心可能恰好是空位。已有烧录字幕也要记录其位置。明确最终目标尺寸；本文的 1080×1920 是示例交付，不是所有渠道固定要求。

> 将这条获授权横版视频做竖版交付，保留主体、关键操作和字幕。先按镜头指出可裁切与不能裁切的部分，给我看低清构图预览；不调用生成式补画、不上传素材，除非我另外同意。完成后逐镜头检查，交付成片与处理方式记录。

## 路线一：保留全画面，固定补边

需要保留全部信息时，可以规范到竖版画布。本包命令使用白色补边、统一帧率并输出无声视频，音轨后续单独处理：

```bash
python3 scripts/media_ops.py normalize-video --inputs ./assets/landscape.mp4 \
  --output tutorial-output/vertical-padded.mp4 \
  --width 1080 --height 1920 --fps 30
```

这条路线没有裁掉内容，却可能让界面字太小。应在手机大小播放检查；可以拆成上下信息区或重新组织镜头，而不是继续放大到模糊。

## 路线二：确认主体居中后裁切

只有确认整段主体都在裁切区内，才使用固定中心裁切。下面按比例放大后裁切，保留原音频（存在时），不会上传：

```bash
ffmpeg -nostdin -n -i ./assets/landscape.mp4 \
  -vf 'scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920,setsar=1' \
  -map 0:v:0 -map '0:a?' -c:v libx264 -pix_fmt yuv420p -c:a aac \
  tutorial-output/vertical-cropped.mp4
```

先创建输出目录并核对 FFmpeg 可用。固定裁切不是自动主体追踪。主体在镜头中移动时，应在可信编辑器逐镜头设置关键帧，或使用经验证的跟踪工具；本包没有实现自动人物跟踪。

## 路线三：重排内容或经授权重新生成

当软件演示文字无法读取时，可改为局部画面与说明区组合；同时保留原截图内容，不凭空生成新的按钮。生成式扩展画面会引入不存在的信息，只有明确同意且模型支持时才使用，不能把它当成无损几何操作。

## 验收与恢复

检查每次切镜前后、主体移动边缘、画面中的文字和字幕安全区。完整解码确认文件可用，再用实际设备观看。HDR/色彩管理或复杂旋转信息的片源，应另做色彩流程验证，本文命令不承诺自动保留全部专业色彩语义。

输出文件错误时重做本地转换即可，不要重新向 Atlas 提交原视频。最终交付说明各镜头采用的处理方式、是否去掉原声音、哪些内容需要用户确认。
