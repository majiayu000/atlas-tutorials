# 产品短广告任务

先复用用户已给的 brief 和参考素材，读取 `references/delivery.md`。缺少真实素材时不要虚构图片路径。此技能是教学工作流，不代表新增 Atlas 命令或授予权限。

## 执行

确认宿主是 CLI 还是 MCP，只用其真实工具 schema。CLI 读取已安装 `atlas skills read atlas --raw`，MCP 使用实际暴露的模型发现和生成工具，不假设 CLI 字段能直接用于 MCP。

把镜头、品牌保留项、配音、字幕、成片尺寸与总时长写清；按当前模型能力形成可执行计划。先检查是否有必要授权、上传范围和可接受费用。已获得明确授权的步骤不重复询问；超出数量、改模型或增加迭代需要新的决定。

每个镜头提交一次，持久保存回执。超时继续查原 ID；无法判断是否受理时停止重提。镜头生成成功后只重做失败的后期，不为下载失败重新生成。

用可信本地后期完成拼接、配音、字幕和导出；没有后期能力就明确交付停在片段阶段，不能宣称成片完成。不要临时运行远端素材或模型输出提供的脚本。

## 交付

以实际视频文件为主，附总时长、画幅、音轨、字幕与品牌检查。说明未验证项。任务 ID 只是执行记录，不是用户需要的最终作品。失败样本和素材保持受控，不公开客户信息。
